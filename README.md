# Smart Tables Demo

The example project for Smart Tables, a table widget for UMG in Unreal Engine 5.8. It holds nine demo
screens. It doesn't hold the plugin.

## Open it

1. Get Smart Tables on FAB and install it to engine 5.8.
2. Open `SmartTablesDemo.uproject`. The project has a C++ module, so the editor asks to build it the first
   time.
3. Press Play. The hub lists the nine demos.

## The documentation

Each demo has a page that says how it's built.

**https://riztazz.github.io/smart-tables/**
